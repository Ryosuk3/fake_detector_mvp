# Быстрый старт

## Первый запуск (5-10 минут)

```bash
# 1. Собрать образы (без загрузки моделей)
docker-compose build

# 2. Запустить сервисы
docker-compose up -d

# 3. Проверить статус
docker-compose ps

# 4. Просмотр логов (первые запуски могут занять 2-5 минут для загрузки моделей)
docker-compose logs -f
```

## Проверка работы

1. Откройте http://localhost:3000
2. Вставьте текст новости (минимум 300 символов)
3. Нажмите "Проверить"

## Что происходит при первом запуске

1. **Сборка образов** (5-10 минут):
   - Установка Python зависимостей
   - Установка Node.js зависимостей
   - Копирование кода

2. **Запуск сервисов** (2-5 минут):
   - Загрузка ML моделей (sentence-transformers, spaCy)
   - Инициализация БД
   - Создание коллекций в Qdrant

3. **Первый запрос** (может быть медленным):
   - Поиск статей через RSS
   - Парсинг и индексация статей
   - Генерация эмбеддингов

## Устранение проблем

### Контейнеры не запускаются

```bash
# Проверить логи
docker-compose logs

# Пересобрать образы
docker-compose build --no-cache

# Очистить все и начать заново
docker-compose down -v
docker system prune -f
docker-compose up -d --build
```

### Модели не загружаются

Модели загружаются автоматически при первом запуске. Если возникают проблемы:

```bash
# Проверить логи NLP сервиса
docker-compose logs nlp_service

# Проверить логи Verifier сервиса
docker-compose logs verifier_service
```

### Проблемы с поиском статей

Система ищет статьи через:
- RSS фиды (ria.ru, tass.ru, vedomosti.ru)
- Парсинг главных страниц
- Векторный поиск в Qdrant

Если статей не найдено, проверьте:
1. Доступность интернета из контейнера
2. Логи search_service: `docker-compose logs search_service`
